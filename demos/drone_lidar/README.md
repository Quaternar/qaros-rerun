# Drone lidar

A drone flies through a scanned basement on the table; its last lidar sweeps and its flight path move through the rooms. Rerun's `drone_lidar` example.

```powershell
uv run demos/drone_lidar/run.py -- --sink qaros --local-app --panels 0.0.0.0:9877
```

What you see, placement, tuning and the data's licence: [docs/demos/drone-lidar.md](../../docs/demos/drone-lidar.md).
