# Air traffic

Ten minutes of ADS-B aircraft over Germany and Switzerland in 3D above the region outlines, with the same traffic on a map panel. Rerun's `air_traffic_data` example.

```powershell
uv run demos/air_traffic/run.py -- --sink qaros --local-app --panels 0.0.0.0:9877
```

What you see, placement, tuning and the data's licence: [docs/demos/air-traffic.md](../../docs/demos/air-traffic.md).
