# Structure from motion

A car's point cloud builds up photo by photo on the table, with the current photo and the reprojection error as panels beside it. Rerun's `structure_from_motion` example.

```powershell
uv run demos/structure_from_motion/run.py -- --sink qaros --local-app --panels
```

What you see, placement and the data's licence: [docs/demos/structure-from-motion.md](../../docs/demos/structure-from-motion.md).
