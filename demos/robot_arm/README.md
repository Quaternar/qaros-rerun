# Robot arm

An SO-ARM100 robot arm, loaded from its URDF, moves through its joint ranges on the table. Rerun's `animated_urdf` example.

```powershell
uv run demos/robot_arm/run.py -- --sink qaros --local-app --panels 0.0.0.0:9877
```

What you see, placement and the data's licence: [docs/demos/robot-arm.md](../../docs/demos/robot-arm.md).
