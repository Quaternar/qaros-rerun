# Robot arm

Rerun's `animated_urdf` example: an SO-ARM100 robot arm loaded from its URDF, moving through its joint ranges.

## Start and stop

```sh
uv run demos/robot_arm/run.py
```

On the QAROS PC, add the viewer's QAROS options after `--`, for example `-- --sink qaros --pairing-code <PAIRING-CODE>`. Ctrl+C or closing the viewer window stops it.

The first start downloads the URDF and meshes (2.9 MB) and records them once, about 2.5 minutes on an Apple M5 Pro, most of it setting up the Python environment; later starts replay the cached 6 MB recording in seconds without network. This is the lightest demo and stays smooth at any headset rate.

## What it shows

- The arm is loaded straight from its URDF, the standard robot description format, with its visual meshes; the collision meshes are hidden.
- Each joint follows joint angles the example generates and logs over time.

## In the glasses

The arm stands on the table at twice its real size: its sweep is about 1.4 m wide, centered 0.65 m above the room origin and 1.7 m in front of it, so its base stays just above a table with the origin marker on it. The demo has no 2D panels. Walk around it to see the joints from the side.

## If something looks wrong

- Arm too big or too small: pass `-- --scale 1.0` (real size) or another value; it overrides the launcher's placement.

## Data

The SO-ARM100 URDF and meshes from [TheRobotStudio](https://github.com/TheRobotStudio/SO-ARM100), Apache-2.0, as shipped with Rerun's `animated_urdf` example (`examples/rust/animated_urdf/data`, with its `LICENSE`); the joint angles are generated by the example.
