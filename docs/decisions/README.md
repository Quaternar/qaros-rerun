# Architecture decisions

Decisions behind qaros-rerun. The numbers are not contiguous: only the decisions about this repository are published here. Decisions about the Rust binding itself belong to the binding in [Quaternar/qaros](https://github.com/Quaternar/qaros). Superseded decisions stay, with a pointer to their successor. Each ADR cites repository paths and public sources (the QAROS header and docs at [github.com/Quaternar/qaros](https://github.com/Quaternar/qaros), Rerun's source, and the Khronos, Microsoft and Rust documentation), and states measurements in place. QAROS behaviour the code works around, with its status, is on the [known issues](../known-issues.md) page.
